aws-cost-report

Automated AWS Cost & Usage reporting CLI and service.

Latest Release: v0.1.0 (0.1.0)

Installation

Homebrew

brew tap smford/homebrew-tap
brew install aws-cost-report

Binary Download

Pre-compiled static binaries are available from the GitHub Releases page:

  • macOS (Apple Silicon - arm64)
  • macOS (Intel - amd64)
  • Linux (arm64)
  • Linux (amd64)

Docker

docker pull ghcr.io/smford/aws-cost-report:v0.1.0

Documentation & Repository

For configuration guides, CLI flags, and report formats, visit the GitHub repository.
