Why aws-cost-report?

⚡ Instant Local Visibility

No need to log in to the slow AWS Billing Console. View categorized monthly infrastructure costs and Month-over-Month deltas directly in your terminal in milliseconds.

🛡️ SRE Budget Guardrail

Block CI/CD deployment pipelines before expensive infrastructure accidents happen using --fail-on-threshold=FLOAT to exit with code 1.

📈 Multi-Format Engines

Output exact fixed-width terminal tables, GitHub Actions Step Summaries (Markdown), structured JSON for pipelines, or CSV for financial reporting.

🏷️ Tag & Account Grouping

Group billing metrics by AWS SERVICE, LINKED_ACCOUNT, or custom cost allocation tags like TAG:Environment or TAG:Project.

🌍 Multi-Currency Support

Automatically detects billing currencies (EUR, GBP, JPY, CAD, AUD, USD) from AWS responses and formats symbols and delta headers accordingly.

Installation

1. Homebrew (macOS & Linux)

brew tap smford/homebrew-tap
brew install aws-cost-report

2. Static Binary Downloads

Direct standalone binaries built for high performance and zero external dependencies:

  • macOS (Apple Silicon arm64)
  • macOS (Intel amd64)
  • Linux (ARM64 / Graviton)
  • Linux (x86_64)

3. GitHub Action

Drop aws-cost-report directly into your GitHub Actions workflow:

- name: Run AWS Cost Report
  uses: smford/aws-cost-report@latest
  with:
    compare: 'true'
    threshold: '500.00'
    format: 'markdown'

4. Docker Container

docker pull ghcr.io/smford/aws-cost-report:v0.6.0

Usage Examples

Instant CLI Help (Zero Latency)

aws-cost-report

Standard Monthly Report

aws-cost-report generate

Month-over-Month Delta Comparison

aws-cost-report generate --compare

Human-Readable Account Labeling

Display a friendly name for the AWS account alongside the 12-digit AWS Account ID in report headers. Automatically discovers your IAM Account Alias via iam:ListAccountAliases, or can be explicitly overridden:

# Explicitly set account alias via CLI:
aws-cost-report generate --compare --name="Production Core"

List Official AWS Cost Explorer Services

aws-cost-report services

Filtering by Service Name or Alias

aws-cost-report generate --filter="Amazon DynamoDB,AWS Lambda"
# Using common aliases:
aws-cost-report generate --filter="S3,EC2,KMS"

Filtering by Cost Allocation Tags

Scope your entire report to tagged workloads with native AWS Cost Explorer server-side filtering:

# Filter by single tag
aws-cost-report generate --tag="Environment=Production"

# Multi-value filter (logical OR) with MoM delta comparison
aws-cost-report generate --tag="Environment=Production,Staging" --compare

# Compound tag filtering (logical AND)
aws-cost-report generate --tag="Environment=Production" --tag="Project=FinOps"

# Combine tag filtering with Linked Account breakdown
aws-cost-report generate --tag="Environment=Production" --group-by="LINKED_ACCOUNT"

Identifying Untagged Costs

When you group costs by an AWS Cost Allocation Tag dimension, AWS Cost Explorer aggregates all resources missing that tag into an empty tag key value. The tool automatically maps this to Untagged / Other.

1. View Breakdown of All Tag Values (Including Untagged Spend)

aws-cost-report generate --group-by="TAG:Environment"

In the generated report table, an Untagged / Other line item reflects all costs incurred by resources lacking the Environment tag.

2. Isolate Untagged Costs Only

Use the --filter option to match the untagged line item and dynamically recalculate report totals:

aws-cost-report generate --group-by="TAG:Environment" --filter="Untagged"

3. Track Untagged Cost Trends Month-over-Month

Add --compare to evaluate whether untagged spend is increasing or decreasing compared to previous periods:

aws-cost-report generate --group-by="TAG:Environment" --filter="Untagged" --compare

📌 Key Considerations

  • Tag Activation: The tag key (e.g., Environment, Owner, Project) must be activated as a Cost Allocation Tag in the AWS Billing and Cost Management console before Cost Explorer can track or group by it.
  • Evaluated Per Tag Key: AWS Cost Explorer does not provide a global "completely untagged" dimension across all potential tags simultaneously; grouping evaluates untagged resources for the specific tag key requested (e.g., TAG:Environment, TAG:CostCenter).
  • Cost Aggregation vs. Resource IDs: The tool reports aggregate monetary figures (e.g., $450.00 on Untagged / Other), but does not enumerate individual resource ARNs or IDs (which would require AWS Config or the AWS Resource Groups Tagging API).

Budget Guardrail

aws-cost-report generate --threshold=50.00
# Returns exit code 1 if total cost exceeds $50.00

GitHub Actions Job Summary

aws-cost-report generate --format=markdown --compare

SRE Workflow with Threshold Outputs

- name: Run AWS Cost Report
  id: cost
  uses: smford/aws-cost-report@latest
  with:
    compare: 'true'
    threshold: '1000.00'
    fail-on-threshold: 'false'

- name: Notify on Breach
  if: steps.cost.outputs.threshold-breached == 'true'
  run: echo "Warning: Cost breached threshold ($${{ steps.cost.outputs.total-cost }})"
